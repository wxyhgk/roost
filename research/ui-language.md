# 为什么 roost 的界面"不像现在的前端"

2026-09-15。起因：用户说「目前的 UI 不是主流的现在的前端 UI」。这份把它拆成可量的差，
而不是感想。

---

## 一、先说结论：它不是没设计，是照**另一套语汇**做的

roost 的设计令牌（`frontend/src/index.css`）：

| | 值 |
| --- | --- |
| 强调色 | **`#ffffff` 纯白** |
| 语义色 | `#ff453a` / `#30d158` / `#ffd60a` —— **Apple 系统色原样** |
| 灰阶 | `#111113` → `#202023` → `#2c2c2e` → `#38383b` → `#46464a` |
| 字体 | `-apple-system` / SF Pro Text / SF Mono |
| 字号 | **只有两档**：`caption 11px`、`body 13px` |
| 注释原话 | `/* Apple-style monochrome, dark */` |

**这是 macOS 原生应用的语汇**，而且做得挺一致。所谓「不像现在的前端」，差的不是精细度，
是**语汇选错了赛道**——Linear / Vercel / shadcn 那一路是另一套。

---

## 二、三个最大的差（按影响排）

### 1. 强调色是纯白 —— 影响最大的一条

全站 35 处用它（`bg-accent` 11、`border-accent` 16、`text-accent` 8）。后果是**每个选中态
都是一块大白**：图标栏选中的那个按钮是深色界面上最亮的东西，比内容还抢眼。

当代做法是一个**低饱和、产品自有的色相**。Linear 用 `#6e78d5` 的柔和靛蓝，被形容为
"reads as product-native rather than branded"——它不是品牌色，是界面自己的语言。

因为是令牌，**换它是一行**，35 处一起变。

### 2. 字号只有两档 —— 没有层次

11px 和 13px，全站就这两个（外加零星的 Tailwind `text-xs` 12px）。标题、正文、元数据、
读数全都一样大，于是**什么都不突出，看起来就"平"**。

当代惯例是 4–6 档，正文 13–14px。roost 的 13px 正文偏小，11px 说明文字是 macOS 桌面的
习惯，不是 web 的。

### 3. 字距是正的

`tracking-[0.02em]`（面板标题）、`tracking-[0.08em]`（小标题）。而当代 UI 字体
（Geist、Inter）普遍用**负字距**收紧——Vercel 的 Geist Sans 在大字号上用到 -0.06em。
正字距是 2010 年代「小写字母间距撑开更清晰」的做法，现在读起来偏松散。

---

## 三、三个其实已经对的 —— **不要动**

- **控件圆角 6px**（`rounded-md`，全站 63 处）。Vercel 的卡片、输入框、标准按钮也是 6px。
  这一条完全在当代惯例上。
- **4px 网格**（Tailwind 默认）。Vercel 明确按 4px 网格排。
- **元数据用等宽字体、11–13px**。Vercel 用 Geist Mono 做 label 和元数据，同样量级。

也就是说：**骨架是对的，皮肤选错了。** 这是好消息——要改的是令牌，不是重排布局。

---

## 四、一个可选项：线怎么画

Vercel 不用 `border`，用 `box-shadow: 0 0 0 1px rgba(0,0,0,0.08)` 画一条零偏移零模糊的
线——不占盒模型，也更淡。

roost 的 `--color-border: #3a3a3e` 压在 `#202023` 的面板上，对比不算低，满屏的框线读起来
比当代产品重。这一条和上面三条是独立的，可以单独试。

---

## 五、可落地的清单（按性价比）

| 改什么 | 成本 | 收益 |
| --- | --- | --- |
| **强调色换成一个低饱和色相** | 一行令牌，35 处跟着变 | 最大。选中态不再是刺眼白块 |
| **字号补到 4–5 档**，正文 13→14 | 令牌加两三档，逐处调用点 | 大。界面立刻有层次 |
| **字距改负**（-0.01em ~ -0.02em） | 三处 | 中。观感立刻"当代" |
| 边框改 box-shadow 画线 | 面较广 | 中。满屏框线变轻 |
| 语义色从 Apple 系统色挪开 | 一行令牌 | 小。但它是「macOS 味」的来源之一 |

**不建议做的**：重排布局、换圆角体系、上阴影堆叠。骨架没问题，动它是白费。

---

## 六、有一件事我要提醒

这份调研能告诉你「当代惯例长什么样」，**但选哪个色相、要不要离开 Apple 语汇，是产品身份
的决定，不是技术判断**。roost 是个终端工作台，长得像原生 macOS 工具也可以是一种立场——
Warp 自己就很"原生"。所以下面那一步应该由你定方向，我来落地。
