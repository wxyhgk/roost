# 资料库前端接入与大弹窗

状态：已实现。合同：backend/LIBRARY_API.md。用户后续明确放弃旧资料，前端已移除迁移流程。

## 最终行为

- NotesView、SelectionSaveBar、CommandPalette 统一使用 frontend/src/library 数据层，服务端搜索与游标分页，选择后加载正文。
- 单条保存 500ms 防抖、持续输入最多约 2s 触发，请求串行、使用最新 revision；旧响应不覆盖新增输入。
- 显示未保存、保存中、已保存、失败、冲突。409 比较当前服务器内容，支持采用远端或另存；410 保留草稿供另存；网络/503 可重试。
- 未保存草稿按资料库和独立草稿键备份；恢复先检查 revision。首次离线新增也保留草稿，待连接后显式恢复。旧备份可导出或手动移除。
- 打开资料面板、窗口聚焦及页面重新可见时刷新；脏编辑器保留本地内容，干净编辑器可更新正文。
- 按用户指示，启动时删除 diy-notes-v1、diy-library-legacy-backup-v1、diy-library-source-v1、diy-library-import:*；不再导入或双写旧集合。保留 API 草稿和当前资料库身份。
- “展开资料库”打开原生 dialog：桌面左右列表/编辑布局，支持笔记与片段切换、摘要、搜索、分页、Esc/关闭按钮。侧栏和弹窗使用同一个 portal 宿主与编辑器实例，展开/收起保留查询、选中记录及草稿。

## 实测与检查

- 隔离后端与浏览器验证笔记创建、自动保存、失败重试、409 内容对比和另存、410 提示、刷新后草稿恢复入口。
- CodeMirror 使用实际键盘输入验证中文代码正文保存；标题、语言与正文均在真实 API 中确认。
- 大弹窗合成 60 条资料：首批 50 条，加载更多得到 60 条后不再显示下一页；搜索与草稿在 Esc 收起后保留，焦点返回展开按钮。
- 资料库功能完整 verify 通过，合计 206 项测试，包含类型检查、构建与源码边界检查。最后面板空白修复后，前端类型检查及 56 项前端测试再次通过。
- 保留既有终端主题、重放以及后端人员的并行改动，未提交 commit。

## 运行中的 404

前端已切换 API 时，旧后端进程未加载资料库路由，/api/library/info 和列表返回纯文本 404 not found。已重载网关，实际后端和前端代理均返回成功。daemon PID 13671 保持，3 个已有终端 PID/instanceId 在重载后核对一致。

## 文件面板顶部空白修复

切换资料库到 FilesView 时，React 复用了同一个 div。portal 子内容卸载后，手动 append 的空宿主仍存在且占据 flex 高度，导致文件工具栏下移。

修正：进入 files 分支显式 contentHost.remove()，并为文件容器和资料库插槽设置不同 key。浏览器验证 notes→files、snippets→展开→收起→files 及反复切换，文件过滤栏均紧贴标题下方。

## 边界

跨设备暂无实时推送；刷新/聚焦触发重查。SQLite 中的显式删除与本地草稿保留分开处理。浏览器配额不足会提示备份失败和导出入口，不能保证被浏览器拒绝的本地写入仍能跨关闭恢复。
