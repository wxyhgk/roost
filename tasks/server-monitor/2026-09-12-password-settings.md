# 设置中修改登录密码

入口：左下角设置 → 登录密码。输入当前密码与两次新密码（至少 6 个字符），保存后立即生效，无需重启服务。保持当前浏览器的 Cookie 和连接，撤销其他浏览器的登录与 WebSocket；不结束终端进程。

## 实现

- `POST /api/auth/password` 经过现有 Origin、Host、登录检查，并验证当前密码。修改与登录共享请求体大小、超时、并发和尝试次数限制。当前密码错误返回 400，避免触发整个工作台的 401 重新登录流程。
- 异步计算新哈希，先以 0600 临时文件写入、同步、原子替换持久目录中的 `auth-password`，成功后更新内存凭据。保存失败保留原密码与会话。没有密码读取接口，也不在响应、日志、localStorage 中保存密码。
- 同一进程的密码修改串行执行；修改前开始、修改后才完成的旧密码登录不能创建新会话。所有操作通过现有认证模块绑定的 WebSocket 生效，不调用终端停止或重建。
- 新增中文、英文表单，提供确认校验、显示/隐藏、提交状态和结果提示；提交时阻止关闭设置，完成后清空密码。网络中断时提示结果尚未确认，不自动重试写请求。
- 认证层显式报告 `canChangePassword` 能力，避免测试/定制服务未配置持久化时在内存中“假保存”。
- 登录覆盖层使用原生模态框。此前打开设置时，过期登录框的输入区域被设置模态框拦截；现在重新登录处于最上层，保留设置中的未提交内容。
