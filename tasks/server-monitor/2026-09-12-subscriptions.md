# 真实 AI 订阅额度

接入研究依据：[接口调研](../../research/ai-subscription-apis.md)。

## 数据入口

- OpenCode Go：官方 GET `/zen/go/v1/usage`，优先本工作台配置的 Key，其次环境变量，再读取本机 OpenCode `auth.json` 中的 `opencode-go` 条目。凭据只在后端使用，前端可设置/移除工作台自己的 Key；不会改写 CLI 登录文件。
- Codex：短生命周期 stdio App Server，只发送初始化、账号和额度读取 RPC。版本来自本项目 package.json；支持多额度桶及可选窗口字段，账号读取前后不一致时丢弃本次结果。不启动线程、发送模型请求或读取浏览器 Cookie。
- Claude：将独立 statusLine helper 安装到持久数据目录，备份原设置并保留已有命令与 stdout。每个 CLI 会话独立保存白名单额度字段，不保存完整 stdin、工作目录或对话；最多保留 32 个采样文件。重复相同输入不伪造新的采样时间。

Claude statusLine 未提供账户 ID，因此明确按报告会话区分，不把额度冒认为当前全局登录账户的额度。首次报告前显示等待；缺失的套餐、续费日期等字段显示 —。

## 展示与调度

- 底部只显示当前所选平台的图标和剩余额度，点击切换与刷新；保留原黑白配色。
- Go 的三个窗口同时约束用量，底部显示使用比例最高的窗口；弹窗列出全部周期及绝对重置时间。Codex 保留各额度桶的范围，主要展示 Codex 桶。
- 页面只轮询当前选中平台，正常每分钟一次，隐藏页面暂停；同页订阅共享请求，迟到响应不能覆盖新连接结果。
- 后端合并并发采集并缓存，查询限流遵守 Retry-After；网络错误指数退避。同一身份的短暂失败保留最后读数；身份变化或凭据失败清除旧额度。
- 上游 401/403 作为订阅状态返回 HTTP 200，工作台自身登录失效仍由认证层返回 401，避免供应商认证问题触发网页退出登录。
- 请求、RPC 输出、凭据文件与采样文件均有大小或时间限制；关闭网关会终止自己的采集子进程。
