# 服务器状态侧栏

右侧服务器图标打开监控，支持原侧栏和展开窗口。8 个分类：概览、CPU、内存、GPU、网络、磁盘、进程、服务。按用户要求统一黑白灰，图标、数字和图表优先；状态使用勾、方框、警告图形和简短文字，含悬停说明与可访问名称。

## 信息范围

- 主机：发行版、架构、内核、硬件型号、虚拟机标识、运行时间、访问地址、默认网卡 IPv4、时区。
- CPU：总占用、估算繁忙逻辑核数、每核负载、逻辑/物理核及可用并行度、插槽、用户态/系统态/空闲/steal、当前/基础/最高频率、缓存、可读取的温度。
- 内存：占用/总量/可用/空闲/活跃、Linux 缓冲/缓存/Slab/脏页/回写、交换区。
- 网络：默认网卡上传下载趋势、每网卡 IPv4/IPv6/MAC、速率/累计流量、链路速度/MTU/双工、错误/丢弃计数、连接状态汇总及最多 100 个监听端点和关联 PID。
- 磁盘：挂载文件系统的空间、类型、读写权限；汇总吞吐、IOPS、累计读写和趋势。
- GPU：型号、总线、显存、占用、温度、功耗、频率、风扇、驱动，取决于硬件与驱动支持。
- 进程：运行/休眠/阻塞/僵尸统计；CPU 排名前 200 个，支持筛选与 CPU/RSS 排序，点名称查看 PID/PPID、用户、RSS/VSZ、线程、优先级和状态。CPU 100% 表示一个逻辑核心。
- systemd 服务：自定义最多 24 个服务名，查看状态、开机启动状态、PID、内存、累计 CPU、运行时长、重启次数、任务数和运行结果。默认 diy-web、diy-terminal、caddy。关注列表原子持久化到数据目录的 monitored-services.json；只读取服务信息，不执行启动/停止等操作。

## 采样与边界

前端按请求完成后 5 秒再刷新，单请求在途，12 秒超时。侧栏关闭、页面隐藏及卸载时停止刷新；恢复可见重新取数。趋势仅保存组件在可见期间最近 5 分钟的最多 60 个真实样本，不是持续历史监控；不跨缺失样本或长时间中断连线，默认网卡变更会清空对应曲线。

后端所有浏览器共享每项采样槽与缓存。常用资源 4 秒、进程 10 秒、GPU/温度/连接 15 秒、文件系统 30 秒、静态主机信息 5 分钟。单项截止时间 3 秒，超时返回旧值/不可用，原采样未结束不会再启动一份。认证在采样前执行，HTTP no-store。进程和网络仅投影允许的字段，不返回命令参数、环境变量、远端连接地址或原始采集对象。

Linux 进程信息采用 16 路异步 procfs 读取，避免每个 PID 启动 cat。服务名严格校验后经 execFile 参数数组传递给 systemctl show；输出、执行时间和配置体积均受限。没有新增常驻后台采样任务或监控 WebSocket。

温度、GPU 等设备无法读取时显示 —；macOS 不提供 systemd，Linux 专有内存字段在其他平台显示 —。网络概览只使用默认网卡，不将虚拟网卡与物理网卡重复相加。磁盘吞吐是已挂载磁盘汇总；APFS 的挂载卷共享容器容量，不能把各挂载点总容量相加当成物理磁盘容量。

依据：[systeminformation 文件系统与 I/O](https://systeminformation.io/filesystem.html)、[网络](https://systeminformation.io/network.html)、[内存](https://systeminformation.io/memory.html)、[GPU](https://systeminformation.io/graphics.html)、[Linux procfs](https://www.kernel.org/doc/html/latest/filesystems/proc.html)。实际实现核对已安装 systeminformation 5.x 的类型和源码；速率第一次采样未知，第二次开始计算。

另发现现有 macOS 大目录文件监听批量关闭可短时阻塞后端：sample 栈停在 uv__fsevents_close / uv_sem_wait，随后恢复。此次监控不修改 watcher；这与新增采样的边界测试和 VPS Linux 验证分开记录。

### 采样进程隔离

实机采样与终端恢复并发时曾出现约 2 秒 HTTP 延迟；另发现服务采样间歇返回空 stdout。独立 Node 进程连续采样正常，线程隔离仍出现空输出，底层原因尚未确定。因此采集放入惰性启动的独立子进程，HTTP 进程只接收结构化快照。多个请求共享一次在途采样；10 秒截止、崩溃恢复与配置代际隔离。超时先终止，1 秒后仍未退出则强制终止，确认退出前不创建替代进程。父进程断开 IPC 时采集器退出。成功但空的服务命令只重试一次；依旧空或不完整的结果被视为失败，保留上次有效数据并标注陈旧，不覆盖为 unknown。
