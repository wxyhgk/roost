# 弱网修复与 fr 发布

对应审查：[后续实验与已复现问题](2026-09-12-next-experiments.md)。本次优先修复已复现的恢复、竞态和资源问题。

## 实现

- 终端允许同一 WebSocket 再次发送完整画面；按顺序解析，只有最新回放完成才能开启输入，拒绝倒退的序号。
- 断线或回放未就绪时不再缓存原始按键；界面明确提示未发送，避免 Claude 退出后把之前的输入送入 OMP。连接正常时原位置预显保留。
- 回放限制按 JSON 编码后的 UTF-8 字节数计算，同时约束 IPC 与 WebSocket。过大的 catchup 改为完整屏幕，完整屏仍过大则明确失败；不能截断 ANSI 字节流。
- 新 owner 宣告 bounded-replay-v1 能力；连接旧 owner 时通过独立 IPC 请求完整屏幕，避免过大的历史回放切断所有终端的共享通道。部署不重启现有 owner。
- 对话自动从已应用游标续接，正文成功合并后才推进游标；请求并发和队列有界，重取快照、切换对话会取消旧请求。
- 工作区首次读取与轮询串行；45 秒超时，完成后等 4 秒再读取；隐藏时暂停，慢响应不覆盖期间的新状态。
- 文件监听按 canonical 目录共享句柄，分离父枚举和子监听的 ENOENT，修复 `/` 释放，使用直接父子索引。
- Caddy 的 `/assets/*` 与 SPA 回退分开；共享目录保留各次发布的哈希文件，真实文件 immutable，缺失文件 404/no-store。

## 边界

- 旧 owner 在保持运行期间使用完整屏幕恢复；其新增有界增量能力在以后安排 owner 重启时生效。
- 对话流未新增心跳；已连接但无任何消息的半开连接仍等待底层 TCP/浏览器报告断开。
- 尚未实施浏览器输出总队列限额、字体/编辑器懒加载、仅监听展开目录等后续实验。
- 完整屏超过安全传输上限会明确显示错误并暂停自动重试，用户可手动重试；不会为恢复网页强制重启 CLI。
