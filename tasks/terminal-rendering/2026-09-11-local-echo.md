# 终端原位置预显

用户选择保留终端原位置打字，服务部署美国 VPS 后由浏览器先显示本地预测，远端回显确认。输入仍立即逐次发送，没有新增发送延迟或重发队列。

## 实现

- `localEcho.ts` 保存当前输入行、待确认编辑和回显匹配状态。新位置先做不可见探测；字母、数字或中文的实际回显与光标一致后建立信任。占位文字消失时以新行重建仍在途中的按键。
- `localEchoView.ts` 用独立 DOM 格子层画浅色预显和预测光标，不修改 xterm 缓冲区。复制、选区、屏幕快照、历史回放与收藏只看到真实终端内容。
- 只预显已成功发送、已完成握手且在前台的键盘输入。排队/拒绝的输入不预显；不新增网络确认语义，画面匹配不能证明命令执行成功。
- 中文组词继续由输入法负责，提交后的文字才参与预显；候选框可以跟随预测光标。普通缓冲区有 scrollback 时，光标查找按 viewport 偏移读取。
- 断线、CLI 切换、退出、失焦、切换会话、滚动、改尺寸、恢复快照、回显不匹配或两秒未确认时撤销预测。同步重绘期间暂时隐藏，完成后对照真实画面。
- 未建立输入预测时不扫描 TUI 光标，避免输出密集的后台终端增加逐帧扫描成本。

## 边界

支持 ASCII、常用中日韩双宽字符及本段输入末尾的退格。行中编辑、跨行折行、方向键、Tab、控制键、括号粘贴、组合字符和复杂 emoji 都原样送远端，暂不预显。新输入位置需要先等一次匹配的真实回显，非回显及掩码输入不凭空显示。没有更改守护进程或后端协议，本次更新只需刷新网页加载前端。

## 验证

- 前端 265 项测试通过；类型检查、生产构建及源码边界检查通过。构建仍有已有的大 chunk 提示。
- `tests/browser/terminal-local-echo.html`：真实 xterm / WebGL，模拟 300ms 回显，Shell 与整屏 TUI 共 23 项检查通过；覆盖格子对齐、中英文、部分回显、退格、快照隔离、输入法定位、重绘不匹配、缩放与清理。预显 DOM 更新约 1–2ms，此数值不是显示器端到端时延。
- `tests/browser/terminal-local-echo-live.mts`：隔离本机 OpenCode，上下行分别延迟 150ms；只输入未提交草稿，不调用模型。检查原位置中文预显、快照隔离、回显撤销和真实退格。
- 上述验证为本机注入延迟，不能等同于美国 VPS 的真实抖动、丢包或网络测量；中文候选框使用合成 composition 事件验证定位，未操作系统输入法候选词。

手工复查：启动前端后访问 `/tests/browser/terminal-local-echo.html`；如需真实 OpenCode，另运行 `node --import tsx frontend/tests/browser/terminal-local-echo-live.mts`，点击连接和验证按钮。测试服务只监听 `127.0.0.1:8791`，关闭页面/停止服务会清理隔离进程。
