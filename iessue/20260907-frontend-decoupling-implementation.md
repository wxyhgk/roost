# 前端解耦实施记录（2026-09-07）

对应调研：[前端耦合审计](20260907-frontend-coupling-audit.md)。本轮落实影响当前交互和异步正确性的接缝，并拆出列表查询、浏览器启动、弹窗宿主与终端轻量入口。

## 已完成

| 范围 | 改动与结果 |
| --- | --- |
| 面板导航 | Shell 区分 show 与 toggle；命令面板跳转当前视图不会收起侧栏。 |
| 文件打开 | 文件树、命令面板、终端链接、pendingSelect 共用 requestOpen，切换文件先检查未保存编辑；重复打开同一路径保留 dirty。 |
| 资料查询 | LibraryQuery 按类型/搜索条件独立维护列表；单条成功保存只更新对应摘要，保留已加载页面；列表请求期间的记录变更在响应后重新应用，避免旧响应覆盖。 |
| 编辑和刷新 | 编辑状态与列表通知分开；显式刷新按已加载页数重查；并发 focus 刷新合并，详情最多 4 个并发请求，只刷新正在使用或未保存的条目。 |
| 详情缓存 | 最多保留 40 条非活动、已保存且无请求的详情；活动条目与未保存草稿不淘汰。 |
| 浏览器启动 | LibraryClient 核心不再在导入时安装浏览器事件；runtime 由 main 显式启动并提供 HMR 清理。保留用户要求的旧资料清理策略。 |
| 资料库弹窗 | useLibraryPresentation 统一管理原生 dialog、稳定 portal target、移除宿主与焦点；搜索框使用显式 ref。 |
| 终端句柄 | 私有 registry 提供注册/订阅；晚挂载、替换、卸载都会重新绑定选区监听；旧句柄注销不会删掉新句柄；查找使用响应式句柄。 |
| 终端输入 | sendToSession 返回 sent / queued / rejected，UI 据此反馈。队列超过 32000 字符拒绝新输入，保留已接受的数据。sent 表示交给连接，不代表 CLI 已执行。 |
| 重连时序 | ready 回调绑定发出握手的 socket generation；旧连接的异步解析完成不能开启新连接输入。 |
| 加载边界 | terminal/public 提供轻量能力，避免普通面板依赖引擎入口；XYZ 预览实际打开时才加载；xterm 输入目标识别归入 adapter。 |

## 验证

- `npm run verify` 成功退出：全部 workspace 类型检查、211 项测试（其中 frontend 61 项）、前端构建、workspace 源码边界检查通过。
- `git diff --check` 通过。
- 新增接缝测试：两页列表保存/删除与不同资料类型隔离；旧列表响应与保存竞争；终端晚注册/替换的选区订阅；输入结果语义；慢解析跨连接代际及队列超限。
- 隔离后端、临时数据库及独立前端端口进行浏览器检查：加载 60 条笔记，修改第二页条目，自动保存后仍显示 60 条；展开弹窗保留正文；命令面板跳转当前笔记视图保持展开；弹窗收起后切文件，顶部布局正常。
- 文件编辑产生 dirty 后，从命令面板打开另一文件，触发原生 confirm。浏览器自动化关闭该原生确认框超时，因此取消后的完整交互未计为通过。
- 构建生成独立 XYZ chunk（591.66 kB）；主 JS 约 5643.00 kB。仍有大 chunk 提示；这不是加载耗时实测。
