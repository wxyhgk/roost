# 侧边栏终端活动状态接入

接口合同：`backend/SESSION_STATUS_API.md`。

## 行为

- 工作区共用一个只读 `/api/session-status` WebSocket，不为状态监控打开 PTY。
- Logo 角标区分近期输出、安静、退出、关闭、状态不可用；连接异常明确显示文字。
- 独立未读点表示“有新终端输出未查看”，安静不代表 AI 完成或等待确认。旧静默提醒的完成暗示文案及勾号也已移除。
- 完整快照删除缺失项；同 monitor 下忽略较旧 revision，同 revision 仅恢复健康，不替换数据。
- 断开或 45 秒无有效快照后清除旧活动显示，自动重连，过期 socket 不得覆盖新状态。
- 已读游标保存在本地 `diy-session-read-v1`，最多 1000 项，写入合并为最多每 500ms 一次，pagehide 同步保存。存储失败不影响终端。
- 新 monitor / instance 建立基线；相同 monitor / instance 的已读状态可以跨刷新保留。

## 呈现确认

终端引擎通过 `onRender` 通知控制器。控制器捕获本次绘制对应的已解析序号，在下一动画帧确认会话仍选中、视口在底部、页面可见并聚焦、终端宿主可见且握手已完成，再报告已读。后续接收或解析但尚未绘制的输出不会被提前确认。

读标记通过依赖注入进入控制器，控制器不导入状态 API 或 React。状态快照序号落后于已呈现序号时保留较新的已读游标；终端先于状态接口完成首次绘制时也保留该证据。

## 验证

- 前端 111 项测试通过，包括完整快照/乱序/心跳、断线超时、未读持久化、新实例基线、初始绘制竞态，以及后台/失焦/隐藏/查看历史/未绘制输出不得标为已读。
- 前端类型检查、构建和包边界检查通过。构建保留现有大包等警告。
- 通过 `ws://localhost:5173/api/session-status`，带 `http://localhost:5173` Origin 成功读取真实快照：9 个会话，包含 closed、quiet、active。仅建立状态连接，未输入命令或创建 PTY。
- 未在主工作台进行整页浏览器视觉验收，避免测试页面接入现有终端并争抢尺寸。
- 未重启后端、daemon 或用户 PTY；未安装覆盖独立稳定工作台。

开发模式通过当前页面的 `/api` 代理访问状态接口；稳定构建将状态作为可选业务能力访问 8787，终端本身继续连接 core。业务接口或 Origin 不可用时仅显示状态连接中断，不影响基础终端。
